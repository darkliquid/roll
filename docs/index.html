Grammar & Help

Basic Dice

Roll N dice with X sides. Percentile and Fate dice have their own notation.

Exploding

Add extra dice on a maximum roll. Compound sums them into one die; penetrating subtracts one from each extra die.

Keep & Drop

Keep or drop the highest or lowest N dice.

Rerolls

Reroll dice that match a condition, either indefinitely or once.

Targets & Failures

Count successes above, below, or equal to a target. f subtracts failures.

Sorting

Sort the rolled dice ascending (s) or descending (sd).

Grouping

Group expressions with { }; separate pooled rolls with commas or add them with +.

Math

Multiply, divide, take a remainder, or raise to a power. The functions floor, round, ceil and abs act on a value, and a die can take a computed number of sides.

Matching

Count matching dice, Yahtzee style. mt returns the number of matches; m only highlights them. An optional count sets how many dice must match and an optional comparison filters the value.

Reference

Based on the Roll20 Dice Rolling Language Specification.
